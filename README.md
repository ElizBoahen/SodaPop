## How to Use SodaPop
Techy
As simple as:
1. Clone repo _or_ download zip.
2. Open your terminal or CMD.
3. Run `npm install`.
4. Run `npm run dev`.
5. Go to `http://localhost:5173` in your browser.

### Non-Techy
If you are *not* a technical person, that is okay! I will walk you through the process.

Quick check-in before we begin. Do you . . .

### Installing Node.js
Node.js lets your computer run SodaPop, and other projects you may want to try.

You can download it here https://nodejs.org/en/download

Choose a version with the words "LTS". "LTS" stands for "long term service" which means less crashing, more stable, and will be supported for longer.
Most go with *the one labeled “Recommended for Most Users”*.

Remember where you downloaded it! Open the file and follow the installation steps.

## Expanding This Project

I like to think about the future of any project I work on. SodaPop could become a web-based AI alternative for big thinkers or soon-to-be creatives. Those individuals have a lot of ideas, store them in many places, and can struggle to keep track of them. In the future, SodaPop could have features like:
- An idea log.
- Change the theme to different "flavors".
- Adjust tone; a creative mode and realist mode.
- Collect data on how long projects take to better advise and support.
